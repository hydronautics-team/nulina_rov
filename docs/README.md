# Документация Nulina ROV

- [Сборка и запуск](build-and-run.md) — первоначальная подготовка компьютера
  аппарата, команда `run nulina`, debug-режим и передача launch-аргументов.
- [Основной README](../README.md) — архитектура платформы, оборудование,
  конфигурация и проверка ROS-топиков.

Все команды запуска из этой документации выполняются непосредственно на
компьютере Нулины. Подключение к аппарату по SSH не является частью launcher.
